## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/brij018/React.git
```

Move into the project:

```bash
cd React/test
```

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Then open the local URL shown in your terminal.
